# Bài thực hành ứng dụng AI
Repository này lưu trữ các sản phẩm của bài thực hành ứng dụng AI, gồm kiểm tra cấu hình máy tính, cài đặt và chạy Python bằng Notepad++, xử lý sự cố Wi-Fi và phần mềm, tạo infographic bằng Canva AI và đánh giá đạo đức khi sử dụng AI.
## Nguồn AI
- ChatGPT: hỗ trợ hướng dẫn và tìm hiểu nội dung thực hành.
- Canva AI (Magic Design): hỗ trợ tạo infographic.
